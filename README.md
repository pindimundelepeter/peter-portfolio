- `CV_Peter_PINDI_MUNDELE.pdf` et `cv-apercu.jpg` : CV

## Mettre le site en ligne (GitHub Pages)

1. Crée un dépôt sur GitHub (ex. `peter-portfolio`).
2. Envoie tout le contenu du dossier dans le dépôt (le fichier `index.html` doit être à la racine).
3. Dans **Settings → Pages**, choisis la branche `main` et le dossier `/ (root)`.
4. Le site sera disponible sur `https://pindimundelepeter.github.io/peter-portfolio/`.
